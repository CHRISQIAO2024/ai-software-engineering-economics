## 研究内容

本研究探讨AI编程助手的局部效率收益能否转化为软件全生命周期成本下降。论文以成本再配置为待检验命题，采用选择性证据评述，重点核验17项核心来源；区分个人任务、工程交付、用户采用与经济价值，提出成本四属性及九项TEC操作化账户。

现有证据覆盖部分时间、费用、活动与质量指标，但不能据此确认完整、同口径的全生命周期净成本变化。论文的贡献定位为证据整理、测量衔接与可检验研究设计，不宣称已经证明普遍的成本迁移规律。
